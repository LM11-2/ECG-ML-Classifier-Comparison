ECG Data and WFDB Setup Instructions

1. Create a parent folder for the raw data. Its name is your choice:
   your-data-folder/
   ├── mitdb/   (MIT-BIH Arrhythmia)
   ├── chfdb/   (BIDMC CHF)
   └── nsrdb/   (MIT-BIH Normal Sinus Rhythm)

2. Download the WFDB-format record files from these PhysioNet database pages,
   then extract each database into its matching subfolder above:
   MIT-BIH Arrhythmia: https://physionet.org/content/mitdb/1.0.0/
   BIDMC Congestive Heart Failure: https://physionet.org/content/chfdb/1.0.0/
   Normal Sinus Rhythm (nsrdb): https://physionet.org/content/nsrdb/1.0.0/

3. Verify each subfolder contains the downloaded .dat files and their matching
   .hea header files. When main.m prompts for a folder, select your-data-folder.

4. Install the WFDB Toolbox for MATLAB and Octave:
   This project uses the toolbox's rdsamp function to read the WFDB records.

   a. Open MATLAB and change to a folder where you want to install the
      toolbox. Do not install it inside this project or the raw-data folder.

   b. Run the following commands in the MATLAB Command Window:

      old_path = which('rdsamp');
      if ~isempty(old_path), rmpath(old_path(1:end-8)); end
      wfdb_url = 'https://physionet.org/physiotools/matlab/wfdb-app-matlab/wfdb-app-toolbox-0-10-0.zip';
      [~, status] = urlwrite(wfdb_url, 'wfdb-app-toolbox-0-10-0.zip');
      assert(status == 1, 'WFDB Toolbox download failed.');
      unzip('wfdb-app-toolbox-0-10-0.zip');
      cd mcode
      addpath(pwd)
      savepath

   c. Verify that MATLAB can find the required reader:

      which rdsamp

      MATLAB should display the path to rdsamp.m.
